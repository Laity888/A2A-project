## Question

客服场景的知识库，有没有现成可下载的中文数据集可以直接拿来用？

## Answer

没有。现成的中文客服数据集（JDDC、DianJin-CSC-Data、CSDS、CrossWOZ 等）都是**对话训练 / 评估语料**，不适合作为 RAG 知识库。

可行回退方案：选一份中文开源项目的官方文档（RAGFlow / LightRAG / QAnything 文档站），导出为 Markdown → 转成 FAQ 问答对 → 向量化进 Milvus。

来源：
- JDDC https://arxiv.org/pdf/1911.09969
- DianJin-CSC-Data https://www.modelscope.cn/datasets/tongyi_dianjin/DianJin-CSC-Data
- CrossWOZ https://huggingface.co/datasets/GEM/CrossWOZ
- RAGFlow docs https://ragflow.io/docs/dev
- LightRAG https://pypi.org/project/lightrag-hku/
