## Question

客服知识库的语料到底用哪一份？

候选方向：
- (a) 中文开源项目的官方文档（RAGFlow / LightRAG / QAnything / Dify 等）—— 许可清晰、结构干净，可完整走通「文档 → 切分 → 向量化 → 检索」。
- (b) 某个真实产品的公开帮助中心页面（需要爬取）。
- (c) 自造一份小型 FAQ（可控，但不够真实）。

需要定：选哪一份、语料从哪里下载 / 导出、预估条目量级、许可是否可商用/可展示。

## Answer

选定 **RAGFlow 官方中文文档（https://ragflow.com.cn）** 作为客服知识库语料。

- **选哪份**：RAGFlow 官方中文文档。许可证 Apache-2.0，可商用、可公开演示、无附加条款；中文文档结构最接近客服问答形态（快速开始 / 用户指南 / 配置 / FAQ / 故障排查）。
- **怎么拿**：爬取导出为 Markdown。站点 `robots.txt` 允许抓取（仅 `Disallow: /contact-us`），有 `sitemap.xml` 可枚举页面；静态文档站，可稳定导出。
- **抓什么**：仅 `/docs` 板块。sitemap 中 `/docs` 共 108 条，其中约 21 条为 `/docs/category/*` 分类索引页（非正文），实际正文页约 86–87 篇；不含 `/blog`。
- **什么形态**：保持文档切片入库，不做 LLM 改写；切分策略留给 ticket 04。
- **规模**：约 200–300 条知识条目，由约 87 篇文档切分后自然形成，对应「中」档规模。
- **许可**：Apache-2.0，允许公开演示与商用，作品集 / 公开仓库无风险。
